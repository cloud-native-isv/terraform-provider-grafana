# Feature Detail: Grafana Data Sources Management

**Feature ID**: 006
**Name**: Grafana Data Sources Management
**Description**: Manage Grafana Data Sources (Resources and Data Sources) via Terraform.
**Status**: Planned
**Created**: 2026-01-13
**Last Updated**: 2026-01-13

## Overview

This feature encompasses the implementation of Terraform resources and data sources to manage Grafana Data Sources. Ideally, it allows users to provision, configure, and retrieve information about Grafana Data Sources (such as Prometheus, Loki, Elasticsearch, etc.) programmatically.

## Latest Review

Initial creation of the feature to support the addition of `grafana_data_sources` data source.

## Key Changes

1. Implement `grafana_data_sources` data source to retrieve all data sources.

## Implementation Notes

- Reuse existing Grafana Go client.
- Ensure proper schema mapping between API response and Terraform schema.

## Future Evolution Suggestions

- Add support for specific data source types configuration validation.
