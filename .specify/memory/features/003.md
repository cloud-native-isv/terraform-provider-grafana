# Feature Detail: Datasource Query Resource

**Feature ID**: 003  
**Name**: Datasource Query Resource  
**Description**: 新增 `grafana_datasource_query` 资源，以声明式方式执行 Grafana 数据源查询并输出可机读结果。  
**Status**: Implemented  
**Created**: 2026-03-16  
**Last Updated**: 2026-03-17

## Overview

该特性面向 Terraform 用户提供统一的数据源查询资源，使查询行为可声明、可复现、可纳入基础设施变更流程，减少脚本化查询与手工排障成本。

## Latest Review

已完成 `/speckit.implement` 主体落地：新增 `grafana_datasource_query` 资源、辅助函数、示例与测试，并完成资源注册与基础回归校验。

1. 新增资源实现：`internal/resources/grafana/resource_datasource_query.go`
2. 新增共享辅助逻辑：`internal/resources/grafana/resource_datasource_query_helpers.go`

6. 完成资源注册：`internal/resources/grafana/resources.go`

## Implementation Notes

- 本特性聚焦“查询执行与结果消费”，不包含数据源创建或仪表板管理能力。
- 需求要求复用项目现有 Grafana 查询能力，避免语义分叉。
- 结果输出应保持机读与稳定，便于下游自动化处理。
- 错误信息需具备可诊断性，支持快速定位输入、权限与上游问题。
- 当前阶段已完成核心实现与定向测试；全量 acceptance 与文档生成仍需在可执行 Terraform/测试环境中继续完成。

## Future Evolution Suggestions

- 增加查询结果筛选与字段投影能力
- 增加批量查询与并发控制策略
