# Feature Detail: Update Grafana SDKs

**Feature ID**: 002  
**Name**: Update Grafana SDKs  
**Description**: 将 Grafana App SDK 与 Grafana Plugin SDK Go 依赖更新到指定最新版本。  
**Status**: Implemented  
**Created**: 2026-02-09  
**Last Updated**: 2026-02-09

## Overview

本特性用于保持 Terraform Provider 与 Grafana SDK 官方发布版本一致，降低依赖风险并获得最新修复，同时确保现有使用场景保持兼容。

## Latest Review

已完成实现与验证：依赖版本已更新，构建与关键内部测试通过，变更记录已补充。

## Key Changes

1. 将 Grafana App SDK 升级到 v0.50.1
2. 将 Grafana Plugin SDK Go 升级到 v0.287.0
3. 同步 go.sum 并保持依赖锁定一致
4. 更新 CHANGELOG 便于追踪版本升级

## Implementation Notes
